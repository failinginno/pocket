# Pocket Finds / 口袋奇物社

3D curiosity shop website with Chinese/English switching and public contract transparency.

## Deploy on Vercel

Import failinginno/pocket. Framework: Other. Root directory: repository root. No install or build step is required. Output directory: dist (configured in vercel.json). No environment variables are required.

## Local preview

Serve dist with any static HTTP server; do not open index.html as a file.

## Scope

The game currently uses browser-local demo trades and settlements. Publishing this frontend does not enable real buy monitoring or automatic mainnet payouts. The private service wallet, monitoring service, deployment UI and local runtime data are intentionally excluded. Public contract source copies are in dist/contract-sources.
